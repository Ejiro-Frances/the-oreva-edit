## Required environment separation

Keep development and production Supabase projects separate. Run fixtures only on a development database. Set DATA_MODE=supabase for live catalogue integration. Set ALLOW_TEST_ORDERS=false for public production. Payment collection is not implemented; public checkout must stay disabled until the next phase is reviewed.

Do not provide production secrets in chat or commit them. Use the deployment platform's environment-secret manager. The public project URL and publishable key are the only Supabase values allowed in browser configuration.
